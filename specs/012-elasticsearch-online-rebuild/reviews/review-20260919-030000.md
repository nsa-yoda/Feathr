# Feature 012 Review Gate

## Scope

Online Elasticsearch rebuild from canonical Mongo events with durable lease state,
live dual-write activation, verified target generation, atomic alias swap, and
read-only status/guarded CLI surfaces.

## Remediation completed

- Replaced the unfalsifiable integration placeholder with a real MongoDB to
  Elasticsearch lifecycle test. It creates canonical events, creates a serving
  generation and alias, runs the rebuild through the production adapters, verifies
  the completed record and alias target, and cleans up its isolated resources.
- Made lease acquisition exclusive with a fixed lock key, owner-bound renewal,
  compare-and-set persistence, and explicit stale-lock recovery behavior.
- Added `SearchProjector.set_target_index()` so the rebuild callback can activate
  and clear a generated target on the actual Feature 010 projector.
- Added failed-target cleanup, bounded failure history, phase ordering assertions,
  activation-before-bulk ordering coverage, safe status error coverage, and adapter
  tests proving remove/add alias operations are one atomic request.
- Added `event_platform.cli` commands matching the operations runbook:
  `search rebuild --confirm` and `search rebuild-status`.
