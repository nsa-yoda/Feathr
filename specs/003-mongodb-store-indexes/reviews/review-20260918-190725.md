## Findings and resolutions

| ID | Severity | Finding | Resolution |
|---|---|---|---|
| F003-C001 | High | Initial design used ascending time ordering, conflicting with authoritative architecture and Feature 008 descending keyset pagination. | Changed query sort, continuation predicate, and every time compound index to descending timestamp/event ID; equality filter prefixes remain ascending. |
| F003-C002 | High | Real Mongo acceptance was initially skipped because no service was configured. | Started a temporary Mongo 8 single-node replica set and passed the complete integration path, including duplicate handling, filters, pagination, aggregation, idempotent bootstrap, and live index definitions. |
| F003-C003 | Important | Integration coverage initially omitted individual filters, repeated bootstrap, exact live definitions, and aggregation. | Expanded the integration test to cover all supported filters, three descending pages with identical-timestamp ties, inclusive bounds, aggregation, two bootstrap calls, and exact custom index names/keys. |
| F003-C004 | Important | Acceptance tasks were initially unchecked while converge wording was broad. | Review evidence and work-log entries now distinguish implementation convergence from completed acceptance gates; T014/T015 are closed with this report and commit. |
| F003-C005 | Important | Raw PyMongo exception causes could retain credentials in traceback chains. | All translated storage errors use cause suppression; tests assert no cause and safe operation-only messages. |
| F003-C006 | Warning | Query filters were unbounded, URL normalization could miss stored values, and validation errors echoed inputs. | EventQuery bounds filter lengths/date ranges, normalizes HTTP URLs, requires UTC timestamps, and hides Pydantic input values. |
| F003-C007 | Bug | PyMongo Async index creation requires a list, aggregate/list-index cursors are awaitable, and BSON reads default to naive UTC datetimes. | Fixed list conversion, awaited async cursor creation, and normalized Mongo UTC datetimes at decode. |
| F003-C008 | Suggestion | Data model and quickstart wording drifted from `EventQuery` and typed UUID callers. | Corrected the model name and clarified UUID storage versus repository input. |
