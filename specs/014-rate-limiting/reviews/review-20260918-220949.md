## Executive Summary

Feature 014 implements mandatory route-class rate limiting with an atomic Redis
Lua token bucket, conservative bounded local fallback, safe direct-peer and
trusted-proxy identity handling, standard denial headers, and structured
request-correlated allow/deny/degraded events. Redis remains optional derived
coordination state and the middleware fails closed with a safe 503 if lifecycle
state is absent. The configured live Redis integration is service-gated and
explicitly skipped locally because `REDIS_URL` is unavailable.
